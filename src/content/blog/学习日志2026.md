## C#单例模式和静态类
1. 单例模式是普通类，可以被继承以及继承，静态类不行
2. 同样是全局唯一，但是静态类不能继承，因此不能单元测试注入。
```C#
interface ILogger
{
    void Log(string message);
}

// 单例可以实现接口 —— 静态类不行
class FileLogger : ILogger
{
    private static readonly FileLogger _instance = new FileLogger();
    public static FileLogger Instance => _instance;
    private FileLogger() { }

    public void Log(string message) => File.AppendAllText("log.txt", message);
}

// 因为实现了接口，可以依赖注入、可以mock测试
void DoSomething(ILogger logger)  // 面向接口编程
{
    logger.Log("hello");
}

DoSomething(FileLogger.Instance);  // 传入单例
DoSomething(new MockLogger());     // 测试时传入mock对象，替换真实实现
```
3. 静态类一般用于工具函数集合
